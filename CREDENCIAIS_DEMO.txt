=====================================================
    FundMe Angola — Contas de Acesso e Demonstração
=====================================================

⚠️ APENAS PARA AMBIENTE LOCAL/DESENVOLVIMENTO.
As palavras-passe abaixo ("password") SÓ se aplicam quando o seeder corre
com APP_ENV=local. Em produção (APP_ENV=production), o seeder gera
automaticamente uma palavra-passe aleatória única para cada conta de
demonstração e imprime-a UMA ÚNICA VEZ no log do comando "db:seed" — essa
password nunca é "password" e não fica registada em lado nenhum. Guarde-a
imediatamente e troque-a a seguir ao primeiro login.

1. ADMINISTRADOR DA PLATAFORMA (Painel Admin & Auditoria)
   - Email: admin@fundmeangola.ao
   - Palavra-passe: password
   - Permissões: Gestão total de campanhas, utilizadores, relatórios, denúncias e transferências.

2. VERIFICADORA MÉDICA / AUDITORA
   - Email: verificador@fundmeangola.ao
   - Palavra-passe: password
   - Permissões: Triagem de documentos médicos privados e laudos hospitalares.

3. SOLICITANTE DE APOIO MÉDICO (Criador de Campanha)
   - Email: solicitante@fundmeangola.ao
   - Palavra-passe: password
   - Permissões: Submeter pedidos de angariação para cirurgias e tratamentos.

4. DOADOR SOLIDÁRIO (Utilizador Comum)
   - Email: doador@fundmeangola.ao
   - Palavra-passe: password
   - Permissões: Fazer doações, acompanhar causas e receber relatórios de transparência.

=====================================================
Nota: Para carregar estas contas na base de dados (caso esteja vazia),
execute o comando no Render Shell ou terminal:
php artisan db:seed --force
