# Portal-Corporativo-do-Talatona
Aplicação web interativa para exploração do ecossistema corporativo e diretório de recrutamento direto em Talatona e Grande Luanda (raio de 50km). Mapeamento de empresas de Telecom, Petróleo &amp; Gás, TI e Logística no Belas Business Park e arredores, com contactos de RH e gráficos setoriais.
